# 📝 C++ To-Do List Manager

A basic To-Do List Management System developed using **C++**.

This project was created to practice fundamental C++ programming concepts such as classes, functions, file handling, and menu-driven programming.

## ✨ Features

- Add and manage to-do items
- Display to-do items
- Menu-driven interface
- File handling for storing data
- Simple command-line interface

## 🛠️ Technologies Used

- **Language:** C++
- **Compiler:** g++
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
